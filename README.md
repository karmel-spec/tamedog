# Tame Dog Official Site

Static website for Tame Dog in the Garage Poster style.

## Files

- `index.html` - homepage with music, shows, merch, gallery preview, and band members
- `gallery.html` - photo gallery page
- `styles.css` - visual design
- `app.js` - mobile menu, gallery filters, and lightbox behavior
- `assets/` - local logo, gallery images, and band member headshots
